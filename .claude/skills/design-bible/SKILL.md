# Design Bible

1. Read `DESIGN.md` at the repo root, all of it. Do not skim.
2. Run its section 0 checklist before designing.
3. Check the request against section 2 (hard rules) and section 13 (decision log). If it conflicts, say so; don't silently break a rule.
4. Design within the tokens, fonts, shapes, motion and sound rules. Original work only.
5. After the change, prove it with section 12 (tests, click-everything, sweeps, width scan, screenshots, Lighthouse, Impeccable detector, Vercel guidelines).
6. If a new design rule was agreed, add it to `DESIGN.md` (and section 13 if something was rejected).
7. Report to John: short 6th-grade summary plus one simple visual.
