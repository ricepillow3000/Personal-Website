# Photo shoot guide (12 photos, ~20 minutes)

**Setup:** phone on a tripod or stand with the self-timer · plain light wall behind you ·
daylight from a window **in front** of you (not behind) · smart-casual outfit.
Nobody else in the frame.

**Bust shots (11):** chest-up, phone at eye level, about 1.2 m away. Don't move the
tripod between shots, so every frame lines up.

| File name | Face |
|---|---|
| `neutral_closed` / `neutral_open` | Relaxed. Open = mid-word, mouth slightly open |
| `neutral_blink` | Relaxed, eyes closed |
| `smirk_closed` / `smirk_open` | One-sided "I got this" smile |
| `excited_closed` / `excited_open` | Big grin (open = laughing/talking) |
| `thinking_closed` / `thinking_open` | Hand on chin, eyes up and to the side |
| `panicked_closed` / `panicked_open` | Wide eyes, hands up — there's a bee |

**Full body (1):** `full_body` — standing, facing the camera, phone ~3 m away at waist height.

Put the files in `tools/photos/` (git-ignored) and run `python tools/ink.py tools/photos public/assets/portrait`.
